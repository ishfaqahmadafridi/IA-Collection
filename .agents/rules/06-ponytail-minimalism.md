# Minimalism and YAGNI

Adapted from EasyCompaign's Ponytail decision ladder.

1. Confirm the requested behavior needs new code.
2. Reuse existing project behavior.
3. Prefer standard-library or native platform capabilities.
4. Prefer installed dependencies over additional libraries.
5. Implement the smallest readable solution that satisfies the requirement.

Do not introduce speculative frameworks, microservices, generic factories or mandatory folder counts. Never reduce authentication, validation, error handling, accessibility or needed regression coverage to save lines.
